
# 📊 Website Traffic Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing website traffic data to understand user behavior, traffic sources, engagement, and conversion performance.
An interactive Power BI dashboard was created to transform raw website traffic data into meaningful business insights.
The dashboard helps identify:
- Website traffic trends
- Major traffic sources
- User engagement
- Bounce rate
- Conversion performance
- Goal completions
- Page-level performance

---

## 🎯 Project Objectives
- Analyze website sessions and users over time
- Identify major traffic sources
- Compare traffic sources and traffic types
- Evaluate user engagement using session duration and engagement rate
- Analyze bounce rate and conversion rate
- Track goal completions
- Identify high-performing and low-performing pages
- Build an interactive business intelligence dashboard

---

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- CSV Dataset
  
---

## 🔍 Key Insights

### 1. Traffic Sources
Organic Search generated the highest number of sessions, followed by Direct traffic.
This indicates that organic search and direct visits contribute significantly to overall website traffic.

### 2. User Engagement
The average session duration is approximately 190 seconds, showing that users spend several minutes interacting with the website.
Session duration varies across different traffic sources.

### 3. Bounce Rate
The overall average bounce rate is approximately 0.49.
This metric can be used to monitor whether visitors are leaving the website without further interaction.

### 4. Conversion Rate
The overall average conversion rate is approximately 6%.
Conversion rates across the major traffic sources are relatively close to each other, with only small differences between sources.

### 5. Page Engagement
The Home page has the highest engagement rate among the analyzed pages.
Products and Blog also show relatively high engagement compared with several other pages.

### 6. Page Performance
The Home page records the highest page-performance count, followed by Products and Blog.
Pages such as Contact and Checkout have lower counts and can be examined further to understand user drop-off.

### 7. Traffic Distribution
Organic Search contributes the largest share of sessions, while Social contributes a smaller share compared with the other major traffic types.
